Stone Paper Scissors Game-

A simple Stone Paper Scissors game built with Python.

This is one of my first Python projects, created while learning the fundamentals of Python programming.

🎮 How It Works-

The computer randomly chooses Stone, Paper, or Scissors.

 The player enters their choice using:
 s → Stone
 p → Paper
 c → Scissors

The program compares both choices and displays the result.
